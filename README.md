# Memo

一个基于 .NET 8 和 Avalonia UI 的 Windows 桌面备忘录应用。采用自定义无边框圆角窗口设计，支持系统托盘、全局快捷键、窗口置顶、贴边收起、长按拖拽重排，以及把单条备忘录拖出成独立便签弹窗。备忘录与设置保存在本机 JSON 文件中。

## 功能特性

### 备忘录管理

- 新增、编辑、删除与重排备忘录
- 内置 Markdown 源码编辑与主题化富文本预览，支持标题、强调、列表、任务项、引用、链接、代码、表格与图片
- 新建时 Enter 保存、Shift + Enter 换行；已有内容停止输入 500ms 后自动保存
- 双击卡片进入编辑态，完成编辑后自动移到列表顶部
- 输入内容与已有备忘录相同时，会提升到首位而非重复新增
- 编辑中的卡片会高亮显示
- 首行为空时忽略提交
- 空列表显示引导卡片，并展示备忘录计数徽章
- 卡片标题取内容第一行，副标题取第二行，附带相对时间戳

### 拖拽与便签弹窗

- 长按卡片（约半秒）后拖拽重排；拖拽期间集合保持不变
- 拖拽时显示浮空卡片、占位框，相邻卡片自动让位动画
- 靠近列表边缘时自动滚动
- 把卡片拖出主窗口后，会在释放位置弹出独立的便签弹窗
- 便签弹窗支持 Markdown 编辑/预览、自动保存、Esc 恢复本次编辑前内容、单独置顶与关闭过渡动画
- 便签时间戳可在「相对时间」和「完整时间」之间点击切换
- 关闭「重复便签」时，拖出已弹出的备忘录会移动其现有便签位置；开启后总是新建便签

### 贴边收起

- 拖动主窗口靠近屏幕任意边缘（约 40 像素内）时，窗口收起为吸附在边缘的小圆角方块
- 方块大小可在设置中调整（30–75 像素，默认 44），调整时有实时预览
- 拖动方块可沿屏幕边缘滑动；向屏幕内侧拖离边缘一定距离后，窗口在光标处展开还原
- 右键方块可打开托盘菜单
- 贴边状态、所在边缘与位置会持久保存，下次启动自动还原
- 可在设置中关闭「启用贴边」，关闭时立即还原窗口

### 窗口与标题栏

- 自定义无边框圆角窗口，支持拖动移动、边缘/角落拖拽调整大小
- 右上角设置、图钉置顶、最小化、关闭按钮
- 置顶按钮带有旋转图标过渡动画
- 主窗口与便签的显示/隐藏带透明度 + 缩放过渡动画
- 所有窗口不占用任务栏，仅通过托盘图标存在
- 单实例运行：重复启动时唤起已运行实例的主窗口

### 系统托盘

- 右键托盘图标打开自定义托盘菜单
- 左键双击（或按设置改为单击）托盘图标恢复/显示主窗口
- 托盘菜单提供：打开备忘录、新建备忘录、窗口置顶（带开启/关闭标识）、退出应用
- 主窗口最小化 / 关闭均可隐藏到托盘

### 全局快捷键（均可配置）

- 切换置顶（作用目标：主窗口或最近激活的便签/教程窗口）
- 最小化到托盘
- 显示主窗口
- 快速添加：把剪贴板内容快速新增为备忘录（可单独启用/禁用，自动去重；可选添加后在鼠标位置弹出便签）
- 被其他应用占用的快捷键会自动跳过注册

### 设置

- **关闭按钮操作**：最小化到托盘 / 直接关闭（首次点击关闭时弹窗询问）
- **快速添加剪贴板内容**：启用/禁用剪贴板快速添加
- **快速添加后自动显示便签**：添加后在鼠标位置弹出便签窗口
- **重复便签**：控制拖出已有备忘录时是移动现有便签还是新建
- **启用贴边**：拖动主窗口到屏幕边缘时收起为方块
- **托盘图标点击习惯**：单击 / 双击显示主窗口
- **贴边方块大小**：30–75 像素滑块，带实时预览
- **界面动效**：跟随系统 / 始终开启 / 关闭
- **快捷键设置**：点击捕获按键，按 Esc 留空，右键取消；带系统保留键与冲突校验
- **教程**：打开内置教程窗口，介绍用法与当前快捷键
- **重置设置**：一键恢复默认（带二次确认）

所有设置修改后自动保存。

### 数据存储

- 备忘录与设置分别保存为 `%AppData%/Memo/memos.json` 与 `settings.json`，本地图片保存到 `assets/`
- JSON 采用 camelCase 与缩进输出，异步保存并使用信号量保证并发安全
- 加载失败静默回退为默认值；删除文件即可在下次启动时重置

## 快捷键一览

### 全局快捷键（系统级，任意界面可用）

| 功能 | 默认快捷键 | 说明 |
| --- | --- | --- |
| 切换置顶 | Ctrl + Alt + T | 置顶/取消置顶最近激活的窗口（主窗口或便签） |
| 最小化到托盘 | Ctrl + Alt + M | 隐藏主窗口到托盘 |
| 显示主窗口 | Ctrl + Alt + N | 显示/恢复主窗口 |
| 快速添加（剪贴板） | Ctrl + Alt + C | 把剪贴板文本添加为备忘录（需启用该功能） |

全局快捷键均可在「设置 → 快捷键设置」中修改：点击对应按钮后按下新组合键，按 Esc 留空该快捷键，右键取消捕获。快捷键必须包含至少一个修饰键，且不能与系统保留组合（如 Alt + Tab、Ctrl + C 等常用组合）或其他应用内快捷键冲突。

### 应用内按键

| 场景 | 按键 | 作用 |
| --- | --- | --- |
| Markdown 新建 | Enter | 创建一条备忘录 |
| Markdown 新建 | Shift + Enter | 换行 |
| Markdown 编辑 | Ctrl + Enter | 立即保存并切换到预览 |
| Markdown 编辑 | Esc | 恢复进入编辑时的内容并退出 |
| Markdown 编辑 | Ctrl + B / Ctrl + I / Ctrl + K | 粗体 / 斜体 / 插入链接 |
| 快捷键捕获 | Esc | 清空该快捷键 |
| 快捷键捕获 | 右键 | 取消捕获 |

### 鼠标操作

| 操作 | 作用 |
| --- | --- |
| 双击备忘录卡片 | 在顶部 Markdown 编辑器中打开 |
| 长按卡片（约 0.5 秒）后拖动 | 调整顺序 |
| 拖动卡片到主窗口外释放 | 在释放位置弹出独立便签 |
| 点击卡片删除按钮 | 删除该条（带上滑动画） |
| 拖动标题栏 | 移动窗口 |
| 拖动窗口到屏幕边缘 | 贴边收起为方块 |
| 拖动贴边方块沿边缘 | 调整方块位置 |
| 拖动贴边方块向屏幕内侧 | 展开还原窗口 |
| 右键贴边方块 / 托盘图标 | 打开托盘菜单 |
| 双击（或单击，视设置）托盘图标 | 显示主窗口 |
| 双击便签 Markdown 预览 | 切换到源码编辑 |
| 点击便签时间戳 | 切换相对时间 / 完整时间 |

## 技术栈

- .NET 8（目标框架 `net8.0-windows`）
- Avalonia UI 11.1（默认启用编译绑定）
- Markdown.Avalonia 11.0.3（Markdown 渲染、代码高亮、图片与表格）
- C#

## 运行环境与构建

需要 Windows 与 .NET 8 SDK。

```bash
cd Memo-avalonia
dotnet run                      # 调试运行
dotnet publish -c Release       # 发布
```

## 数据存储

应用会在用户 AppData 目录下创建 `Memo` 文件夹：

```text
%AppData%/Memo/
```

主要文件：

- `memos.json`：备忘录列表
- `settings.json`：关闭行为、快捷键、快速添加、贴边、动效等设置
- `assets/`：粘贴、拖入或选择的本地图片，按 SHA-256 哈希去重保存

删除这些文件后，应用会在下次启动时使用空数据和默认设置重新创建。

## 使用说明

1. 在顶部 Markdown 编辑器输入内容，按 Enter 保存为新备忘录（Shift + Enter 换行）。
2. 双击已有备忘录编辑；停止输入 500ms 后自动保存，Ctrl + Enter 完成并预览，Esc 恢复本次编辑前内容。
3. 使用工具栏插入格式；图片可粘贴、拖入、选择文件或通过 HTTPS 地址插入。
4. 点击卡片删除按钮删除该条。
5. 长按卡片并拖动可以调整顺序；拖出主窗口则在释放位置弹成独立便签。
6. 点击标题栏图钉按钮切换窗口置顶，或使用全局快捷键 Ctrl + Alt + T。
7. 拖动主窗口到屏幕边缘可贴边收起为方块，拖回屏幕内侧展开。
8. 复制任意文本后按 Ctrl + Alt + C 快速添加为备忘录。
9. 右键托盘图标打开托盘菜单，双击托盘图标显示主窗口。
10. 更多用法可在「设置 → 教程」中查看。

## 开发说明

- 备忘录集合由 `MainViewModel` 管理，持久化逻辑在 `JsonMemoStorage` 中。
- 应用设置由 `JsonSettingsStorage` 保存，启动后异步加载并应用到主窗口和全局快捷键服务；主窗口在设置加载完成后才首次显示，以支持启动即贴边。
- 贴边收起逻辑在 `MainWindow.Docking.cs`：检测边缘距离、方块拖动、展开还原与状态持久化。
- 长按拖拽排序封装在 `DragReorderManager`：拖拽期间不修改集合，仅在释放时调用 `MainViewModel.MoveItem`。
- 便签由 `MemoPopoutWindow` 实现，`App` 维护便签列表并决定置顶快捷键的作用目标。
- 窗口过渡动画由 `WindowTransitionController` 统一提供，动效受 `MotionPreferences`（跟随系统/开启/关闭）控制。
- 由于使用了 Windows 托盘、全局快捷键和单实例能力，当前项目按 Windows 桌面应用配置。若要支持其他平台，需要替换托盘、快捷键和目标框架相关实现。
